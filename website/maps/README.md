# Maps

Place sanitized/demo PMTiles files here if they are suitable for public redistribution.

Production map extracts are intentionally omitted because they may contain precise location information and can be regenerated from OpenStreetMap-derived data.

Expected demo filenames:

- `office-one.pmtiles`
- `office-two.pmtiles`

The `.gitignore` excludes PMTiles by default. Remove that rule only after reviewing the data and licensing implications.
