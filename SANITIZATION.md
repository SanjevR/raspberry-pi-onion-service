# Sanitization Report

This package was prepared for public GitHub use.

## Intentionally omitted

- live Onion Service address
- Onion Service public and secret identity files
- SSH public and private keys
- production `authorized_keys`
- exact usernames used in production
- internal IP addresses and subnet
- Wi-Fi SSID and credentials
- office addresses, phone numbers, and email addresses
- real staff names and photographs
- production PMTiles/map extracts
- production fonts and third-party vendor binaries
- full equipment inventory and asset serial numbers
- screenshots, logs, backups, and shell history
- patient information and ePHI

## Replaced with placeholders

- organization name
- office locations
- map coordinates
- Onion hostname
- staff public key
- trusted LAN subnet
- server filesystem paths where appropriate

Review the repository again before publishing, especially after copying any production file into it.
