# Security Policy

## Public-repository scope

This is a sanitized educational repository. Do not open issues or pull requests containing production credentials, private keys, live network details, patient information, or private office documentation.

## Never publish

- Tor `HiddenServiceDir` contents
- SSH private keys
- recovery-key media contents
- production `authorized_keys`
- Wi-Fi passwords
- private network diagrams or device credentials
- internal medical-office inventory with serial numbers
- patient records or ePHI

## Reporting a security concern

Use a private contact channel controlled by the repository owner. Do not post exploit details or sensitive findings in a public issue.
