# Staff Email — Raspberry Pi Safe Shutdown

**Subject:** Important — Raspberry Pi Server Shutdown Procedure

Hi everyone,

The Raspberry Pi server in the East Windsor office is the small computer board/chip sitting on the laptop cooling platform with the fans underneath it.

If it ever needs to be moved, removed, disconnected, or relocated, please do not simply unplug the power cable while it is running. Like any computer, it must be shut down properly first. Abruptly removing power could corrupt files or damage the operating system on its storage card.

Please follow the attached safe-shutdown procedure before moving or disconnecting the Raspberry Pi.

If there is any uncertainty about whether it has shut down correctly, please contact the administrator before unplugging or moving it.

Thank you,
